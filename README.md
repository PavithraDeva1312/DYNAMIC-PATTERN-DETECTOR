# DYNAMIC-PATTERN-DETECTOR
Configurable 4-bit pattern detector using Verilog HDL

-> Project Overview:

This project implements a Finite State Machine (FSM) using Verilog HDL to detect a binary pattern in a serial input stream.

Unlike a conventional fixed-pattern detector, this design uses a configurable pattern register (pattern_to_detect) to specify the pattern to be detected

-> Tools:
Language: Verilog HDL

Simulator: ModelSim Intel FPGA Edition 2020.1

Editor: GVim
